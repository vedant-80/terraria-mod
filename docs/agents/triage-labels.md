# Triage labels

Use these exact GitHub labels for the canonical roles:

| Role / label | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate the issue |
| needs-info | Waiting on the reporter for more information |
| ready-for-agent | Fully specified and ready for an autonomous agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Apply the label corresponding to the role requested by the skill.
